# Shopify Translator

**Shopify Translator** is a Chrome extension that translates Shopify Admin, Shopify apps, web pages, and selected text directly in your browser.

## Shopify Translator

Working with Shopify apps in a language you don't understand?

Page Translate helps you translate Shopify Admin and app interfaces without changing the app itself.

### What you can translate

- Shopify Admin
- Shopify apps
- Shopify app interfaces
- Web pages
- Selected text
- Embedded app content
- Dynamic content

### Translate Shopify Apps

Many Shopify apps don't provide every language that merchants need.

With Page Translate, you can open a Shopify app in Shopify Admin and translate its interface directly from Chrome.

No changes to the Shopify app are required.

### Features

- Translate Shopify Admin
- Translate Shopify apps
- Translate entire pages
- Translate selected text
- Translate dynamic content
- Multiple target languages
- Quick translation from the browser
- Works with modern web applications

## How it works

1. Install Page Translate.
2. Open Shopify Admin.
3. Open the Shopify app you want to translate.
4. Start Page Translate.
5. Choose your target language.
6. Translate the page.

## Use cases

### Shopify merchants

Use Shopify apps in your preferred language without waiting for the app developer to add localization.

### Shopify agencies

Translate Shopify Admin and third-party apps when working with stores in different countries.

### Shopify developers

Quickly inspect Shopify apps and admin interfaces in another language while developing or testing stores.
